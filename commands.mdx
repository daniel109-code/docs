Helply includes slash commands for asking questions, training its learning file, managing tickets and forum threads, and opening your dashboard.

## How command permissions work

Command permissions are managed in the **Permissions** tab of your server dashboard.

- You can choose which roles can run each Helply slash command.
- If you leave a command with no roles selected, access is limited to members with **Manage Server**.
- You can also configure optional per-role **`/ask cooldowns`** in the same tab.

Read more here: [Permissions](/permissions)

## Command reference

<AccordionGroup>
  <Accordion defaultOpen icon="circle-question" title="/ask">
    Ask Helply a question and get a private answer.

    **Options**

    - `message` - required: Your question for Helply
    - `file` - optional: A file or screenshot to include
  </Accordion>
  <Accordion description="Plus / Pro" icon="brain" title="/train">
    Summarize recent human messages into Helply’s learning file.

    **Options**

    - `channel` - required: Channel containing the relevant discussion
    - `focus` - required: Short focus statement about what Helply should learn
    - `messages` - required: Number of recent human messages to scan, from `1` to `100`

    <Note>
      `/train` is a Plus / Pro feature. [Learn more.](/billing)
    </Note>
  </Accordion>
  <Accordion icon="brain-arrow-curved-right" title="/learn">
    Add a quick manual note to Helply’s custom learning file.

    **Options**

    - `note` - required: Plain-text note Helply should remember
  </Accordion>
  <Accordion description="Plus / Pro" icon="chart-column" title="/overview">
    Show the most common ticket issues over a selected time window.

    **Options**

    - `hours` - optional: Number of hours to summarize, from `1` to `168`
    - `dm` - optional: Send the summary to you in a DM

    <Info>
      Hourly overviews must be enabled in the [Analytics](/analytics) tab for `/overview` to work.
    </Info>
    <Note>
      Overview analytics is a Plus / Pro feature. [Learn more.](/billing)
    </Note>
  </Accordion>
  <Accordion icon="comment-xmark" title="/close">
    Close the current ticket and save a transcript.
  </Accordion>
  <Accordion icon="check-double" title="/resolve">
    Mark the current forum thread as resolved.
  </Accordion>
  <Accordion icon="message-exclamation" title="/unresolve">
    Mark the current forum thread as unresolved.
  </Accordion>
  <Accordion icon="arrow-right-to-bracket" title="/dashboard">
    Get the link to your Helply dashboard.
  </Accordion>
  <Accordion icon="bell-exclamation" title="/reminder stop">
    Stop inactivity reminders in the current ticket.
  </Accordion>
  <Accordion icon="bell-ring" title="/reminder resume">
    Resume inactivity reminders in the current ticket.
  </Accordion>
  <Accordion icon="file-circle-question" title="/help">
    Get help with how to use Helply.

    <Info>
      By default, anyone can run this command.
    </Info>
  </Accordion>
  <Accordion icon="comments-question-check" title="/support">
    Access the Helply Discord support server.

    <Info>
      By default, anyone can run this command.
    </Info>
  </Accordion>
</AccordionGroup>
