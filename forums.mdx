The **Forums** tab is where you configure Helply for forum-based support.

Use this tab if your server handles support through Discord forum channels. Here, you can choose which forums Helply should monitor, define status flows, control inactivity handling, and customize how forum updates are shown.

<Note>
  Forum embed customization is a **Plus / Pro** feature. [Learn more.](/billing)
</Note>

## What the Forums tab does

<Columns cols={2}>
  <Card icon="list-check" title="Choose forum channels">
    Select which Discord forum channels Helply should manage.
  </Card>
  <Card icon="tag" title="Filter by tags">
    Choose which forum tags Helply should respond in.
  </Card>
  <Card icon="clipboard-medical" title="Track thread status">
    Define how resolved, unresolved, inactive, and escalated threads are handled.
  </Card>
  <Card icon="snooze" title="Manage inactivity">
    Configure and customize the reminder and inactivity timing, as well as follow-up behavior.
  </Card>
  <Card icon="user-lock" title="Control locking">
    Decide when resolved or inactive threads should be locked automatically.
  </Card>
  <Card icon="palette" title="Customize updates">
    Adjust forum embeds, status messages, and button styles on supported plans.
  </Card>
</Columns>

## Settings reference

<AccordionGroup>
  <Accordion defaultOpen icon="hashtag" title="Forum channels">
    Start by selecting the forum channels Helply should manage.

    Once selected, Helply can use those forums for support workflows and apply the rules you configure in this tab.
  </Accordion>
  <Accordion icon="arrow-progress" title="Forum status flows">
    Helply supports forum thread states for:

    - **Resolved**
    - **Unresolved**
    - **Inactive**
    - **Escalated**

    You can map forum tags to each of these states so Helply can update thread status more clearly inside your workflow.

    Helply automatically applies the relevant forum tags. This makes it easier for staff and members to see what still needs attention, what has gone inactive, and what has already been resolved or escalated.
  </Accordion>
  <Accordion icon="lock" title="Locking behavior">
    The Forums tab includes controls for thread locking behavior.

    ### Lock on resolve

    Enable this if you want Helply to lock a thread when it is marked as resolved.

    ### Lock on inactive

    Enable this if you want Helply to lock a thread when it is marked as inactive.

    These settings help keep solved or abandoned threads organized without requiring manual cleanup.
  </Accordion>
  <Accordion icon="bell-ring" title="Inactivity reminders">
    Helply can automatically follow up when a forum thread goes quiet.

    When **Inactivity reminders** are enabled, Helply can send a reminder after a set delay, then mark the thread inactive later if there is still no response.

    Reminders reset whenever a new message is sent.

    ### Reminder delay

    Choose how long Helply should wait before sending an inactivity reminder.

    ### Inactive after

    Choose when Helply should mark the thread inactive if there is still no reply after the reminder.

    This helps prevent old support posts from staying open indefinitely while still giving members a chance to continue the conversation.
  </Accordion>
  <Accordion icon="brake-warning" title="Unresolved helper and human escalation">
    The Forums tab also includes an unresolved helper flow.

    If Helply’s last answer did not solve the issue, you can configure a follow-up message that asks for more detail and optionally offers escalation to a human.

    This works well when you want Helply to keep the conversation moving without forcing users to start over.
  </Accordion>
  <Accordion description="Plus / Pro" icon="palette" title="Forum customization">
    Helply supports forum embed and button customization for forum workflows.

    This includes customization for:

    - main forum response embeds
    - reminder embeds
    - resolved and unresolved status embeds
    - inactive and escalated status embeds
    - human escalation embeds
    - unresolved helper embeds
    - status button labels and button styles

    <Note>
      Forum embed customization is a **Plus / Pro** feature. [Learn more.](/billing)
    </Note>
    On paid plans, you can customize embed titles, descriptions, colors, and status button styles to better match your server’s workflow and branding.
  </Accordion>
</AccordionGroup>

## Recommended forum flow

<Steps>
  <Step title="Select the forum channels Helply should manage">
    Choose the support forums where Helply should be active.
  </Step>
  <Step title="Map tags to your status states">
    Define how resolved, unresolved, inactive, and escalated threads should appear in your workflow.
  </Step>
  <Step title="Set inactivity timing">
    Choose when reminders should be sent and when quiet threads should become inactive.
  </Step>
  <Step title="Decide when threads should lock">
    Enable automatic locking for resolved or inactive threads if you want a cleaner forum workflow.
  </Step>
  <Step title="Customize the experience">
    On supported plans, adjust embeds and buttons so the forum flow matches your server’s tone and branding.
  </Step>
</Steps>
