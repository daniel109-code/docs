Analytics help you understand how Suppio is being used and where support volume is coming from.

<Note>
  Analytics dashboard access is available on paid plans.
</Note>

## What analytics show

Suppio tracks support activity across configured surfaces, including Discord tickets, Discord forums, chat widget conversations, and support page conversations.

The **Analytics** tab includes a trend chart and the selected agent's usage log. It can include:

- opened conversations
- resolved conversations
- escalated conversations
- escalation rate
- credits used per conversation or credit event
- an **All usage** log for every credit-generating event
- conversation history

## Time ranges

Analytics can be viewed over common windows such as 7 days, 30 days, and 90 days.

Use these views to understand:

- whether support volume is rising
- which periods create more escalations
- whether more context is needed
- how credits are used over time

## Practical review workflow

1. Check escalation rate.
2. Open recent escalated conversations.
3. Add missing answers to context.
4. Review usage after context updates.
5. Adjust behavior or escalation instructions if handoffs are too frequent or too rare.
