## Plan tiers

Helply currently offers three plan tiers.

## Billing intervals

Paid plans support both **monthly** and **yearly** billing.

On the pricing page, you can switch between monthly and yearly billing before checkout.

## Upgrading a server

When you choose a paid plan, Helply asks you to select the server you want to upgrade.

Only eligible servers appear in checkout. In general, that means:

- Helply must already be added to the server
- You must have the required admin access for that server
- The server must be eligible for the selected upgrade

After selecting a server, Helply redirects you to **Stripe** to complete checkout.

## How billing works

Billing is managed per server, which means different servers can be on different plans at the same time.

For example, one server can stay on Free while another runs on Pro.

Plans renew automatically unless they are cancelled.

## Managing subscriptions

The [Billing page](https://helplybot.xyz/dashboard/billing) shows your current paid servers and their subscription details.

For each active subscription, you can view:

- server name
- current plan
- billing interval
- subscription status
- expiration or end date, when available

If you own the subscription, you can also manage billing actions from this page.

## Canceling and resuming

You can cancel a subscription from the Billing page.

When cancelled, the subscription stays active until the end of the current billing period. After that, the paid plan ends.

If a subscription is already set to end at period end, you can resume billing before it expires.

## Payment history

The Billing page also includes **Payment history**.

This shows recent invoices and billing activity for plans you purchased, including:

- server
- plan
- billing period
- amount
- payment status
