Helply is an AI support bot for Discord that helps communities answer questions, manage support workflows, and keep responses grounded in your actual docs and server knowledge.

---

## AI support inside Discord

Helply can answer member questions directly inside your server and help reduce repetitive support work. It is built around support environments, so the core experience is focused on tickets, forum posts, and other help channels rather than generic chat responses.

Helply also supports slash commands for asking questions, learning from messages, summarizing recent issues, and managing support flows.

## Smart routing for support channels

Helply can be told exactly where it should operate. You can configure it for ticket channels, categories, and forum-based support flows, then adjust how it behaves in those spaces.

This gives you control over where Helply is active, how it handles support conversations, and how it fits into your existing workflow instead of forcing you into a single system.

Read more here:

- [Setup](/setup)
- [Overview](/overview)

## Knowledge-based answers with context

Helply answers questions using the information you provide instead of relying on generic replies. You can connect docs, notes, websites, and other context sources so responses stay grounded in your own server’s information.

Read more here:

- [Context](/context)

## Ticket and forum workflow support

Helply is built for actual support operations, not just Q&A. It can help with ticket-based workflows and forum-based workflows, including status handling, reminders, and escalation paths.

For forums, Helply supports flows for states like resolved, unresolved, inactive, and escalated. This makes it easier to keep threads organized and avoid support requests getting lost.

Read more here:

- [Forums](/forums)
- [Actions](/actions)

## Custom AI behavior

Helply can be customized to fit the tone of your community. You can adjust things like emoji usage, personality, and custom response instructions so replies feel appropriate for your server.

This helps Helply feel more natural in different environments, whether you want something more professional, more friendly, or more direct.

Read more here:

- [Behavior](/behavior)

## Model and optimization controls

Helply includes controls for model-related settings and response optimization. This gives you a way to balance quality, speed, and cost depending on what your server needs.

There is also a dedicated area for optimization settings, including FAQ-related controls and other efficiency-focused options.

Read more here:

- [Intelligence](/intelligence)
- [Optimize](/optimize)

## Command permissions and access control

Helply supports role-based command access. You can choose which roles are allowed to use each command, and you can also configure extra controls like `/ask` cooldowns.

This gives server owners tighter control over who can use member-facing commands and staff-focused commands.

Read more here:

- [Permissions](/permissions)

## Analytics and visibility

Helply includes analytics features that help you understand what is happening across your support system. This includes issue summary views and dashboard-level visibility into usage and activity.

The main dashboard also surfaces high-level stats such as AI responses, connected servers, and community reach.

Read more here:

- [Analytics](/analytics)

## Usage tracking

Helply tracks usage on a per-server basis so you can see how many credits have been used, how many remain, and when limits reset.

This makes it easier to manage activity across communities and understand how heavily Helply is being used.

- [Usage](/usage)

Helply includes billing tools for managing paid plans across servers. You can view which servers are subscribed, access receipts, and manage subscription state from the dashboard.
