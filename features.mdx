## AI support inside Discord

Helply can answer member questions directly inside your server and reduce repetitive support work. It is designed around support environments, so the core experience is centered on tickets, forum posts, and other help channels rather than generic chat replies.

Helply also includes slash commands for asking questions, learning from messages, summarizing recent issues, and managing support flows.

This gives you control over where Helply is active, how it responds, and how it fits into your existing workflow.

## Ticket and forum workflow support

Helply is built for actual support operations, not just question-and-answer use. It can support ticket-based workflows and forum-based workflows, including status handling, reminders, and escalation paths.

For forums, Helply supports states such as resolved, unresolved, inactive, and escalated. This makes it easier to keep threads organized and prevent support requests from getting lost.

## Command permissions and access control

Helply supports role-based command access. You can choose which roles are allowed to use each command and configure additional controls such as `/ask` cooldowns.

This gives server owners more control over both member-facing commands and staff-focused commands.
