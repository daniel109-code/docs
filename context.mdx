The **Context** tab is where you give Helply the information it uses to answer questions.

Context is required for Helply to send messages. If a server has no context, Helply will not respond. Once context is added, Helply can use that knowledge to generate grounded answers instead of generic replies.

<Warning>
  Helply requires context to function. Without it, Helply will not respond.
</Warning>

## Supported upload methods

Helply supports several ways to add context.

<AccordionGroup>
  <Accordion defaultOpen icon="file-text" title="Plain text">
    Paste raw text directly into Helply.

    This works well for short notes, policies, FAQs, instructions, or any other information you want Helply to learn without uploading a file.
  </Accordion>
  <Accordion icon="upload" title="File upload">
    Upload a TXT file from your device.

    This is useful when you already have support content, guides, or notes saved locally and want to add them as context.
  </Accordion>
  <Accordion icon="globe" title="Website upload">
    Paste direct URLs to scrape live pages into a single webdata file.

    This works well for help centers, public docs, landing pages, or any other web content you want Helply to reference.
  </Accordion>
  <Accordion icon="book-bookmark" title="Mintlify docs">
    Connect a Mintlify docs site to sync documentation into Helply.

    This is useful if your product docs already live in Mintlify and you want Helply to answer from that source directly. Paste the link to any page in your documentation to connect it.
  </Accordion>
  <Accordion icon="book-open-cover" title="GitBook">
    Import a GitBook space into Helply.

    This is useful for teams that keep their documentation in GitBook and want Helply to use it for support replies. Paste the link to any page in your documentation to connect it.
  </Accordion>
  <Accordion icon="message-question" title="Discord forum posts">
    Index selected forum posts and tags.

    This is useful when important answers already live inside your server’s forum channels and you want Helply to learn from them.
  </Accordion>
  <Accordion icon="radio" title="Follow channels">
    Track the latest messages from selected channels.

    This is useful when your server has announcement, update, or knowledge channels that Helply should stay aware of over time.
  </Accordion>
</AccordionGroup>

## Custom learning feed

The Context tab also includes a **Custom learning feed**.

This is a special context file that Helply builds from:

- `/train`, which summarizes recent channel logs
- `/learn`, which adds quick manual notes

One context slot is reserved for this file.

Use the **View / Edit** button to review and manage what has been added to the learning feed.

<Note>
  The custom learning feed gives Helply a simple way to retain high-value notes and summaries without creating a separate file every time.
</Note>

## Context limits

Each server has context limits based on its plan.

<Columns cols={3}>
  <Card horizontal title="Free:">
    **6 files**\
    Max size: **800KB** per file
  </Card>
  <Card horizontal title="Plus:">
    **10 files**\
    Max size: **3 MB** per file
  </Card>
  <Card horizontal title="Pro:">
    **20 files**\
    Max size: **5 MB** per file
  </Card>
</Columns>

If you reach your plan limit, you will need to remove an existing context item or upgrade your plan before adding another.

## Refreshing and syncing

Some context sources can stay up to date automatically after upload.

For supported web-based sources, Helply can refresh synced content on an interval so your docs stay current over time.

## What to put in Context

Good context usually includes the same information a strong human support team member would rely on.

<Columns cols={2}>
  <Card icon="book" title="Documentation">
    Product docs, setup steps, and troubleshooting guides.
  </Card>
  <Card icon="clipboard-list" title="Policies and playbooks">
    Policy notes, support playbooks, and internal instructions.
  </Card>
  <Card icon="seal-question" title="FAQs and known issues">
    Repeated questions, known issue explanations, and reusable answers.
  </Card>
  <Card icon="clipboard-question" title="Server knowledge">
    Forum answers, update posts, and important channel content worth reusing.
  </Card>
</Columns>

**The better your context is, the more accurate Helply’s responses will be.**

<Info>
  If Helply’s responses are inaccurate, the most common cause is missing or incomplete context around the question being asked.
</Info>
