title: "Frequently asked questions"
description: "Quick answers to common Suppio setup and usage questions."
---

## Does Suppio require context?

Yes. Suppio requires active context before it can respond through deployment methods or the API.

## Can one agent be used in multiple places?

Yes. An agent can be deployed to supported surfaces such as Discord, chat widget, support page, and API. Configure each deployment separately.

## Does the API create tickets automatically?

No. The API returns action signals such as `escalate_to_human`, `mark_resolved`, and `suggest_title`. Your backend decides what to do with them.

## Can I use a custom domain for the support page?

Yes, on Pro and Enterprise plans. Use a public hostname such as `help.example.com`.

## Why did a web chat close?

Chat widget and support page conversations close when Suppio marks them resolved or escalated. Start a new chat to continue.

## Where did my deployment settings go?

Open **Deploy** to set up a method. Enabled **Chat widget**, **Support page**, and **API** methods then appear directly in the agent sidebar. Discord settings appear inside the **Discord** group after the bot is connected.

## Can Suppio talk to customers in Discord voice channels?

Yes. On Plus, Pro, and Enterprise, Suppio can offer a temporary private voice session from a configured Discord ticket or forum post. The customer must explicitly accept before Suppio creates the channel. See [Discord live support](/live-support).

## Does screen sharing use Discord Go Live?

No. On Pro and Enterprise, the customer clicks **Share screen** and chooses a tab, window, or screen through a secure Suppio page. Suppio processes occasional still images in memory instead of connecting to or recording a Discord Go Live stream.

## Does every model call use credits?

Yes. User-facing answers and supporting AI workflows count. **Usage > All usage** shows credit-generating events, while conversation details show totals for supported chat and Discord conversations.
