Getting Helply ready only takes a few steps. [Add the bot](https://discord.com/oauth2/authorize?client_id=1432092138526605412&permissions=8&redirect_uri=https%3A%2F%2Fapi.helplybot.xyz%2Fbot-invite%2Fcallback&response_type=code&scope=applications.commands%20bot) to your server, open that server in the dashboard, and work through the main settings tabs.

---

## 1. Add Helply to your server

Open the [**Servers**](https://helplybot.xyz/dashboard/servers) page in the dashboard and click **Add server**. Once Discord finishes the invite flow, refresh your server list if needed, then open the server you want to configure.

You can also invite the bot to your Discord server [here](https://discord.com/oauth2/authorize?client_id=1432092138526605412&permissions=8&redirect_uri=https%3A%2F%2Fapi.helplybot.xyz%2Fbot-invite%2Fcallback&response_type=code&scope=applications.commands%20bot).

## 2. Open your server dashboard

Helply is configured per server, so you can use different routing, context, behavior, and permissions across different communities.

If you are having trouble finding the dashboard for your server, simply run `/dashboard` in your Discord server.

## 3. Choose where Helply should respond

Start by setting your support destinations. Depending on your workflow, you can configure Helply for either:

- ticket channels or categories
- forum channels

Read more here:

- [Overview](/overview)
- [Forums](/forums)

## 4. Set your support roles

Choose the roles that count as your support team. Helply uses this to understand when staff are involved and how it should behave in support conversations.

Read more here:

- [Overview](/overview)

## 5. Add context

Give Helply the information it should use when answering questions. This is where you connect docs, notes, websites, and other knowledge sources so replies stay accurate and grounded.

Read more here:

- [Context](/context)

<Warning>
  Helply requires context to function; Helply will not respond without it.
</Warning>

## 6. Review your server settings

Once the basics are in place, go through the remaining tabs and adjust anything you want for your server:

- [**Actions**](/actions) for ticket and workflow behavior
- [**Optimize**](/optimize) for FAQ and response efficiency settings
- [**Behavior**](/behavior) for tone and response style
- [**Intelligence**](/intelligence) for model-related settings
- [**Permissions**](/permissions) for command access

## 7. Test Helply

After setup, run a quick test in your server to confirm Helply is responding in the right places and using the context you added.

<Note>
  Helply will not respond unless you enable it at the top of the dashboard first.
</Note>

<Warning>
  Helply will not respond to you if you have an ignored/staff role. In other words, ensure you don't have the staff role that Helply intentionally ignores before testing.
</Warning>
