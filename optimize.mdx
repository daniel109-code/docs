The **Optimize** tab is where you tune how Helply retrieves context and uses FAQ answers to respond more efficiently.

Use this tab to control how many file search results Helply can pull into a support reply and to build pre-generated FAQ entries that can reduce credit usage on matching first messages.

## What the Optimize tab does

  <Card icon="align-justify" title="Control retrieval breadth">

  <Card icon="upload" title="Create FAQ entries">

## Settings reference

<AccordionGroup>
  <Accordion defaultOpen icon="search" title="Max file search results per query">
    This setting controls the cap on results returned per file search for support replies.

    You can choose:

    - **No limit**
    - **1** through **10**

    If you set a lower number, Helply will use fewer search results when building a reply. This can keep retrieval tighter and more selective.

    If you choose **No limit**, Helply can use as many relevant results as needed.

    ### When to lower this setting

    A lower cap can be useful when you want:

    - tighter context selection
    - lower credit usage per response

    ### When to leave it higher

    A higher cap or **No limit** can be useful when:

    - you want Helply to search more broadly before replying
    - you want responses to prioritize completeness and coverage
  </Accordion>
  <Accordion icon="clipboard-question" title="FAQ">
    The FAQ section lets you create pre-generated answers for common support questions.

    Helply can publish these entries so they are ready to use when a matching first message comes in. This helps reduce ticket credit usage on repeated questions and can make common issues faster to handle.

    ### FAQ entry limits

    The Optimize tab shows:

    - total FAQ entries, up to **50**
    - open FAQ editors, up to **10 at once**

    You can add a new FAQ entry directly from this section.
  </Accordion>
  <Accordion icon="square-pen" title="Open FAQ editors">
    Helply lets you work on multiple FAQ entries in parallel.

    You can keep up to **10 editors** open at the same time. While generation is running, editors can be collapsed so you can keep working more easily.

    If you have multiple draft entries open, you can also generate them together from this section.
  </Accordion>
  <Accordion icon="lightbulb" title="Suggest questions">
    Helply can suggest new FAQ questions from your current context files.

    This tool suggests up to **5** possible FAQ questions based on the information already uploaded in your server context.

    This works well when you already have strong docs and want help turning that information into reusable support answers.
  </Accordion>
</AccordionGroup>

## Recommended setup

<Steps>
  <Step title="Start with retrieval settings">
    Choose whether you want a tighter cap on file search results or broader retrieval for maximum coverage.
  </Step>
  <Step title="Add your highest-frequency questions first">
    Create FAQ entries for the issues your support team sees most often.
  </Step>
  <Step title="Use suggested questions to expand coverage">
    Review Helply’s suggested FAQ ideas and turn the strongest ones into reusable entries.
  </Step>
  <Step title="Monitor performance and adjust">
    If replies feel too broad, lower the file search cap. If answers need more coverage, raise it or remove the limit.
  </Step>
</Steps>
